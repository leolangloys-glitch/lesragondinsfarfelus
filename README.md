# Les Ragondins Farfelus

Site officiel du festival de musique et de magie Les Ragondins Farfelus,
au Domaine de Briquemault (Loiret).

## Lancer le site sur son ordinateur

```bash
npm install
npm run dev
```

Puis ouvrir l'adresse affichée (en général http://localhost:4321).

## Construire le site

```bash
npm run build
```

Le site prêt à publier est généré dans le dossier `dist/`.

Les décisions et règles du projet sont dans [CLAUDE.md](CLAUDE.md).
